# Pandas Analyzer & Data Visualization Project

## Overview
This project is an object-oriented Python application built to analyze and visualize sales data. It makes use of **Pandas**, **NumPy**, **Matplotlib**, and **Seaborn** to process sales records, perform data cleaning, extract key statistics, and generate clear visualizations for decision-making.

## Project Structure
- `sales_analyzer.py`: Main program code containing the class implementation and interactive CLI menu.
- `sample_sales_data.csv`: Synthetic sales dataset generated automatically if an external CSV file is not provided.
- `output_plots/`: Output directory where generated plots are saved as `.png` images.

## Features
1. **Data Acquisition & Cleaning:** Handles missing data using median imputation and fixes data types.
2. **NumPy Array Integration:** Shows vector slicing, indexing, and element-wise computations.
3. **Data Operations:** Split, combine, filter, sort, and construct pivot tables.
4. **Statistical Computations:** Measures variance, standard deviation, and percentiles.
5. **Data Visualization:**
   - **Matplotlib:** Bar chart, line graph, scatter plot, pie chart, histogram, and stack plot.
   - **Seaborn:** Heatmaps and boxplots.
6. **OOP Principles:** Demonstrates inheritance, encapsulation, destructors, and operator overloading.
